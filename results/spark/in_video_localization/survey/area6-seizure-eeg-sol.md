## 評估與適用性

- **沒有可信的單一「patient-specific 減 cross-patient 差距」數字。** 上表的 patient-specific 與 cross-patient event 結果來自不同研究及評分規則，不能相減。AAN 的同表 fine-tune 比較較接近受控比較，但只量測 segment sensitivity，未證明 alarm 效果。
- [SzCORE framework（Dan et al., *Epilepsia*, 2025）](https://pmc.ncbi.nlm.nih.gov/articles/PMC12489712/) 同時建議 sample-based 與 event-based 計分；[timescoring](https://github.com/esl-epfl/timescoring) 提供實作。其 **any-overlap** event matching 可在很晚才觸發時仍算偵測成功；單靠 event sensitivity 不足以評估 onset alarm。
- 對本專案，主要報告 **event sensitivity、false alarm events/24 h，以及 onset-to-first-alarm latency 分布**。另報每個 anomaly video 的 within-video 指標。先固定 alarm threshold、連續 positive window 的合併規則及 event matching tolerance，再比較方法；不要把 window false-positive rate 當成 false alarms/hour。
- **Whole-recording normalization 不 causal**。當前 window 的 feature 可立即評分，但 scene baseline 只能由先前 window 建立。Novelty-gated 更新可減少事件污染；它不能保證在沒有可靠初始正常片段時有效。
- 已查來源未提供足以比較上述方法的 **per-video／within-stream localization** 結果。TUSZ 與 Siena 上符合相同 alarm 定義的 patient-specific 對 cross-patient 數值比較亦未核實。

## 優先試驗

1. **Novelty-gated causal baseline + probe。** 使用過去且未觸發 alarm 的 feature 建立穩健 scene baseline；保留原 feature 與 residual 作為並列輸入，避免強制相減抹除事件訊號。以 HOLMES-VAU window 標籤檢查短事件是否污染 baseline。
2. **EpiSMART 式的小型 probe 更新。** 用 video labels 建立初始 probe；僅在模擬標籤到達後，以選取的 window 標籤更新。分開報告「有標籤更新」與「無部署標籤」兩種條件。
3. **Scene-adversarial feature probe。** 在訓練資料中抑制 scene identity，同時保留 anomaly window 分類訊號。先以儲存的 feature 做消融；以 event sensitivity、false alarms/24 h 和 latency 決定是否值得增加模型複雜度。
